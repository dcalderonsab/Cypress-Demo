# CodeChallengeDCS
CodeChallengeDCS
The following project has been developed on Cypress 10.3.1 version and Node v14.7.3.


If you do not have Node:
To Install Node JS use the following url: https://nodejs.org/es/download/

When is installed, check the node version with the following commnad: node -v


Once the code has been download in your local and if you do not have Cypress already installed, run the following command on the project paht: npm install cypress --save-dev


If you do not have mochawesome, run the following command in your project path:
npm i --save-dev cypress-mochawesome-reporter
